# Fontes verificadas

- Artigo-base: InboundCycle, atualizado em julho de 2026.
- Fonte primária: repositório `webmachinelearning/webmcp` do W3C Web Machine Learning Community Group.
- Implementação: documentação oficial do Chrome, atualizada em 7 de agosto de 2026.

## Fatos usados no roteiro

- WebMCP permite expor funções JavaScript e formulários HTML como ferramentas com descrições e schemas estruturados.
- A proposta complementa integrações de backend como MCP; não as substitui.
- O agente e o usuário compartilham a mesma página, o contexto visual e a sessão da aba.
- O Chrome oferece APIs imperativa e declarativa, com flag local e Origin Trial a partir do Chrome 149.
- Limitações oficiais: foco em fluxos locais com pessoa no circuito, visita prévia à página para descobrir tools e possível refatoração em interfaces complexas.
